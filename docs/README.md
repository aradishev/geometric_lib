## Circle: 
**S = πR²**
> Формула площади круга

Реализуется с помощью функции area, которая принимает радиус окружности

**P = 2πR**
> Формула периметра круга

Реализуется с помощью функции perimeter, которая принимает радиус окружности

## Square
**S = a²**
 > Формула площади квадрата

Реализуется с помощью функции area, которая принимает сторону квадрата a

**P = 4a** 
 >Формула периметра квадрата 

Реализуется с помощью функции perimeter, которая принимает сторону квадрата

## Rectangle
**S = ab**
> Формула площади прямоугольника

Реализуется с помощью функции area, которая принимает стороны прямоугольника a и b

**P = 2a + 2b**
> Формула периметра прямоугольника

Реализуется с помощью функции perimeter, которая принимает стороны прямоугольника a и b

## Triangle

**S = (ah)/2**
> Формула площади треугольника

Реализуется с помощью функции area, которая принимает сторону треугольника a и высоту h опущенную на эту сторону

**P = a+b+c**
> Формула периметра треугольника

Реализуется с помощью функции perimeter, которая принимает стороны треугольника a, b и с
